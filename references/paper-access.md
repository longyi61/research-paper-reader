# 文献获取

## 身份与版本

用 DOI、完整标题、作者、年份、期刊交叉核验。先精确搜索，再用标题变体和作者年份检索。工作论文与发表版标题或年份可以不同，必须用作者、内容和版本说明验证联系。多个候选无法排除时，呈现最小候选信息让用户选择。

UTD 期刊是主要使用场景，不以期刊身份替代质量判断。需要判定是否属于 UTD 清单时，核验 UTD 官方当前清单及其适用年份，不凭记忆固定列表。

## 全文选择

用户提供可读的本地 PDF、上传全文、可直接读取的 PDF 链接，或本任务已取得匹配全文时，核对身份和版本后直接阅读，无需先检索 Zotero。缺失附录或页面不可读时，仅补充获取相关材料。

只有标题、citation、DOI、文献落地页，或所给文件不存在、不可读、身份不匹配时，进入 Zotero 优先流程。说明文件的具体问题；不能把文件读取失败当作 Zotero 库中没有论文。

本技能不附带 Zotero 连接器、PDF 解析器或浏览器控制工具。按当前环境实际提供的能力执行；工具缺失时说明缺少哪项能力。若有可用全文，继续阅读；否则尝试可用的获取路径，仍无法取得全文时请用户提供 PDF 或完成必要登录。

## Zotero 优先

1. 发现并使用当前环境提供的 Zotero 插件能力，读取其操作规范；不要假设某个工具名、插件版本或硬编码安装路径存在。
2. 在当前 Zotero 插件提供本地辅助程序时，先执行其 `status --json`，再按插件规范查询。条目定位后检查附件、附件路径和全文。论文精读请求包含读取相关全文的授权。
3. 使用索引文本定位章节；涉及数学、图表、扫描页或提取异常时读取实际 PDF 并查看页面。若 PDF 在云端但未同步到本地，明确这一状态。
4. 分别报告：库中未找到条目、条目存在但全文缺失、附件未下载、连接不可用、全文解析失败。连接不可用时不能宣称库中没有论文。

若 Zotero 能力不可用，说明无法检索文献库；有 Edge 控制能力时继续 EBSCO/SSRN 流程。不能假设安装此技能已经安装或配置了 Zotero 插件。

仅使用已有的读取接口；不直接修改 Zotero 数据库。无需为精读安装新的管理桥接插件。下载论文不自动授权创建条目、导入附件或保存 Zotero 子笔记。

## Edge 中的 EBSCO 与 SSRN

全文缺失时，先简短告知已核实的状态，然后继续检索。用户已经要求此获取流程，无须再询问是否搜索。

1. 通过可用浏览器控制能力明确选择 Microsoft Edge，优先复用相关机构或数据库的已登录标签页。遵守控制工具的初始化、操作和完成规则。
2. EBSCO 用 DOI 或准确标题查找；需要时组合作者、期刊和年份。机构入口与数据库配置从现有会话和实际页面确认，不写死机构地址或 CINAHL 等其他学科数据库配置。
3. 若 EBSCO 无全文、入口不可用或需要等待用户登录，可独立继续 SSRN 检索。SSRN 按标题和作者定位下载页面，记录稿件日期或版本标识。
4. 使用实际可见的全文或下载入口。需要账号、机构认证或验证码时，请用户在 Edge 完成；不得将登录失败报告为论文不存在。用户交互尚未完成时，只继续不依赖该步骤的工作。
5. 用户指定的下载路径优先。未指定时使用任务可写的临时或输出目录，记录绝对路径。检查文件真实格式、大小、可读性，以及首页元数据；登录页面或错误 HTML 不算 PDF 下载成功。
6. 核对正文、参考文献和相关附录。独立在线附录需另外获取。记录读到的是正式发表版、作者接受稿、工作论文还是版本未确定。

对每个来源完成一次身份匹配后的合理获取尝试；新证据支持时再重试，避免循环点击失败链接。用户明确要求 Edge，Edge 不可用时说明具体阻碍，不静默换用其他浏览器。其他合法来源可作为补充选项，不能声称已完成 EBSCO/SSRN 流程。

## 获取不完整时

摘要只能支持摘要级解释。缺少附录时可分析正文，但相关证明标明未验证。关键公式无法读取时，先尝试其他可用版本或页面渲染；仍无法确认则请求必要材料，不补造公式。

将实际来源和版本集中放在笔记末尾的来源索引；没有影响内容的版本差异时不在讲解开头另写读取报告。材料缺失阻碍回答时简短说明具体阻碍。不要用“已核实摘要”“没有逐篇复核”等流程话术替代研究内容。相关登录信息、访问令牌及临时签名下载地址不写入笔记。
